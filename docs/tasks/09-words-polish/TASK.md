## 요구사항
- **셔플:** 학습을 시작할 때와 "다시 하기"를 누를 때마다 카드 순서를 무작위로 섞는다. ③·⑥ 목록 자체는 seq 순서 그대로다.
- **힌트:** 한→영 카드에 "힌트 보기" 버튼. 누르면 `maskHint` 결과가 보이고, 다음 카드로 넘어가면 다시 숨겨진다. 답을 확인한 뒤에는 힌트 버튼을 숨긴다 (정답이 이미 보이므로).
- **③ 목록 줄:** 왼쪽 `단어 ♪ (오답 N)` / 아래 발음기호, 오른쪽 한국어 뜻(`*` 제거, 길면 2줄까지 말줄임). 상태 뱃지는 빼고, 습득한 단어는 뜻 글자를 초록으로 표시해 상태를 남긴다.
- **한국어 보기 토글:** 기본은 보기. 누르면 모든 줄의 뜻을 숨기거나 보인다. 화면을 나갔다 와도 앱이 살아 있는 동안은 선택을 유지한다.
