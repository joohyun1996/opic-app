## 0단계 콘텐츠: 문자·발음 (스페인어)
- 장 구성 예시 (장마다 설명 + 문제 8~10개):
  1. 알파벳 27자: 이름과 소리, 영어와 다른 글자(ñ, ll, rr, j, h 묵음)
  2. 모음 5개 a e i o u: 항상 같은 소리
  3. 자음 규칙: c·g(뒤 모음에 따라 소리 변화), qu·gu, z, v=b
  4. 강세: 끝에서 두 번째 음절 규칙, 강세 부호(á é í ó ú)
  5. 읽기 연습: 쉬운 단어·인사말을 소리 내어 읽기
- 문제 유형: 기존 choice / blank 재사용
  - 예: "ñ의 소리는?", "다음 중 h가 묵음인 단어는?", "강세가 있는 음절을 고르세요"
- 예문마다 발음 듣기(TTS, `es-ES` 또는 `es-MX`) 버튼. 설명의 한국어 표기는 참고용임을 밝힌다
