## 요구사항

### 1. 채점 규칙 (`core:common/Flashcard.kt`) — 웹 규칙에서 변경
웹 시절 영→한 규칙("뜻 전체와 완전 일치")은 `"주요한; 큰"`, `"(피해를) 가하다"` 같은 뜻 형식 때문에 사실상 맞힐 수 없다. 아래로 바꾼다.

- **영→한 `gradeMeaning(input, meaningKo)`**
  - 뜻 후보 만들기: 맨 앞 `*` 제거 → `;`와 `,`로 나눈다 → 각 후보에서 괄호 `( )` 안의 내용을 지운다 → 앞뒤 공백 제거 → 빈 후보는 버린다
  - 비교용 정규화: 공백과 문장부호(`. , ! ? ~ ·`)를 모두 지운다
  - 입력이 후보 중 **하나와 정규화 후 같으면** 정답
  - 예: `"주요한; 큰"` → "큰" 정답, "주요한" 정답, "주요" 오답 / `"(피해를) 가하다"` → "가하다" 정답, "피해를 가하다" 오답 / `"영향받지 않은; 꾸밈없는"` → "꾸밈 없는" 정답
- **"맞았어요" 버튼:** 영→한에서 오답 판정을 받았을 때만 보인다. 누르면 그 답을 정답으로 바꿔 기록한다 (뜻이 여러 가지라 자동 판정이 놓치는 경우 대비). 한 문제에 한 번만 누를 수 있고, 오답 기록을 지우고 정답 기록으로 바꾼다.
- **한→영 `gradeWord(input, word)`:** `input.trim().lowercase() == word.lowercase()`
- **힌트 `maskHint(word)`:** 3글자 이상은 첫 글자 + 가운데 글자 수만큼 `_` + 마지막 글자, 글자 사이에 공백 (`"contract"` → `"c _ _ _ _ _ _ t"`). 2글자 이하는 첫 글자 + `_` (`"ox"` → `"o _"`). 하이픈·공백은 그대로 보인다.

### 2. 학습 기록
- 답을 확인할 때마다 `recordResult(wordId, correct, now)`를 한 번 호출한다.
- "맞았어요"로 바꾸면 방금 기록을 정정한다: wrongCount −1, correctCount +1. **같은 트랜잭션**에서 처리하고 음수가 되지 않게 한다. `UserWordDao`에 정정 함수를 추가해도 된다 (스키마 변경 아님).
- 상태는 `wordStatus(correctCount)`를 그대로 쓴다 (3회 이상이면 습득).

### 3. 화면 (`:feature:words`)
- **③ Day 단어 목록** (`day/{day}` 경로를 이 화면으로 교체)
  - 상단: "Day N", 습득 수/전체 진행률 바
  - 목록: 단어, 발음기호, ♪ 버튼, 상태 뱃지(신규/학습중/습득, `words-ui.md` 색). 오답 기록(wrongCount > 0)이 있으면 빨간 "오답 N" 작은 표시
  - 하단: "영→한 학습", "한→영 학습" 버튼 2개
- **④⑤ 플래시카드**
  - 그 Day의 단어 전체(deleted 제외)를 seq 순서대로 한 장씩. 상단에 "3 / 40" 진행 표시
  - ④ 영→한: 영어 단어 + ♪ + 발음기호 → 한국어 입력. ⑤ 한→영: 한국어 뜻 + 품사 + 힌트 → 영어 입력
  - "확인" → 정답(초록 테두리 + ✓) / 오답(빨간 테두리 + ✗ + 정답 표시). 정답·오답 모두 예문과 예문 번역을 함께 보여 준다. ⑤에서 정답이면 ♪ + 발음기호도 보여 준다
  - "다음"으로 넘어간다. 입력이 비어 있으면 "확인"이 비활성
  - 중간에 뒤로 가면 확인 대화상자 없이 ③으로 돌아간다 (이미 답한 기록은 남는다)
- **결과 화면:** 맞힌 수/전체, 틀린 단어 목록(단어 + 뜻). "다시 하기", "목록으로" 버튼
- ③으로 돌아오거나 홈·Day 목록으로 돌아가면 습득 수가 새 기록을 반영한다
- 키보드: ④는 한국어 입력, ⑤는 영어 입력(자동 대문자·자동 수정 끔). 키보드가 입력칸과 "확인" 버튼을 가리지 않는다 (`imePadding`)

### 4. 발음 (♪)
- Android `TextToSpeech`, `Locale.US`. 앱 안에서 하나만 만들어 재사용하고, 화면을 떠나면 정지한다.
- TTS 엔진이 없거나 영어 음성 데이터가 없으면 ♪ 버튼을 비활성으로 두고, 처음 한 번만 "기기 설정에서 영어 음성을 설치하세요" 안내를 보여 준다. 앱이 죽지 않는다.
- 네트워크 권한을 추가하지 않는다.
