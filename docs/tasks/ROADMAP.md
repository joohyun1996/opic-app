## 2. 스페인어 추가 (영어 기능 완료 후)
- 시험 목표 확인 필요 (OPIc 스페인어 / DELE)
- 미리 정리할 일:
  - language 필드가 없는 테이블(`user_words`는 Word 경유, `grammar_reviews`)의 언어 구분 방법 → Migration 필요 여부를 그때 TASK로 결정
  - 문법 데이터를 언어별 파일로 나누기
  - Whisper·Gemma의 스페인어 성능 확인
  - TTS 음성
  - 홈·메뉴의 언어 전환
- 메뉴의 "중국어 (HSK) 준비 중" 항목은 이때 "언어 선택"으로 바꾼다
