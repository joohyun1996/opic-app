## 목표
단원 결과 화면의 "직접 써 보기"를 연다. 사용자가 단원의 `writingTask`에 맞춰 영어 문장을 **타이핑**하면, 기기 내 Gemma 3n E4B가 문장마다 맞음/틀림과 고친 문장을 준다. 설명은 **오류 유형별 고정 한국어 문구**를 먼저 보여 주고, 모델이 쓴 설명은 "AI 설명"으로 구분해 보조로 둔다 (2026-10-07 사용자 결정).

근거: 쓴 글에 대한 교정 피드백이 문법 정확도를 높인다 (Kang & Han, 2015). 산출(output) 연습은 OPIc 답변 준비와 같은 형태다.

## 요구사항

### 1. 문장 나누기 (`splitSentences`)
- `.` `!` `?` 뒤 공백 기준으로 나눈다. 빈 문장 제거, 앞뒤 공백 제거
- 흔한 약어에서 나누지 않는다: `Mr.` `Mrs.` `Ms.` `Dr.` `a.m.` `p.m.` `e.g.` `i.e.` `U.S.`
- 최대 **5문장**까지만 교정한다 (문장당 약 22초 — 5문장이면 약 2분). 6문장 이상이면 "앞의 5문장만 교정합니다" 안내

### 2. AI 교정 준비 화면 (일반 사용자용)
TASK 05의 debug 검증 화면에만 있던 기능을 사용자 화면으로 만든다.
- 엔진 상태(`LlmEngineState`)를 한국어로 보여 준다: 모델 없음 / 다운로드 중(진행률 %, MB) / 불러오는 중 / 준비됨 / 실패(이유)
- 모델 없음: "AI 교정을 쓰려면 모델(약 N GB)을 한 번 받아야 합니다. Wi-Fi에서 받으세요." + HF 토큰 입력칸(저장돼 있으면 "저장됨") + "다운로드" 버튼
- 토큰은 기존 `HfTokenStore`에 저장. 화면에 토큰 값을 다시 보여 주지 않는다
- "직접 써 보기"를 눌렀을 때 준비되지 않았으면 이 화면을 먼저 보여 준다
- 문법 단원 목록 상단에도 "AI 교정: 준비됨 / 준비 필요" 상태 한 줄

### 3. 쓰기 화면
- 단원의 `writingTask.promptKo`(크게), `promptEn`(작게), "최소 N문장"
- 여러 줄 입력칸. 영어 키보드 우선(자동 수정 끔). 입력한 문장 수를 실시간 표시
- "교정 받기": 문장 수가 `minSentences` 미만이면 비활성
- 교정 중: "2 / 3 문장 교정 중… (문장당 약 20초)" + 취소 버튼. 문장마다 결과가 나오는 대로 아래에 바로 붙인다 (전부 끝날 때까지 기다리지 않는다)
- 화면을 떠나거나 취소하면 진행 중인 생성을 멈춘다 (코루틴 취소)

### 4. 교정 결과 (문장마다 카드)
- `buildCorrectionPrompt(sentence)` → `engine.generate(…, timeoutMs = 120_000)` → `parseCorrection(raw, sentence)` (TASK 05 그대로)
- **맞음:** 초록 ✓ + 원문
- **틀림:** 원문(틀린 부분 `original`에 빨간 밑줄 또는 취소선) → 고친 문장(초록), 그리고 오류마다:
  1. 유형 이름 + **고정 설명 문구** (아래 표) — 크게, 먼저
  2. `original → fix`
  3. "AI 설명" 접힘 영역 안에 모델의 `explanationKo` (기본 접힘, 회색, "AI가 쓴 설명이라 틀릴 수 있어요")
- **InvalidJson / Contradiction / 시간 초과 / 엔진 오류:** "이 문장은 교정하지 못했습니다" + "다시 시도" 버튼 (그 문장만 다시)
- 하단: "다시 쓰기"(입력 유지), "단원 목록"

### 5. 오류 유형별 고정 설명 문구 (`errorTypeGuide(type)`)
초안 (GPT가 검토 후 다듬어도 됨, 바꾸면 HANDOFF에 기록):

| type | 이름 | 고정 설명 |
|---|---|---|
| tense | 시제 | 언제 일어난 일인지에 맞춰 동사 형태를 바꿔야 해요. 끝난 과거는 과거형, 늘 하는 일은 현재형, 지금 하는 일은 be + -ing. 이야기 중간에 시제가 바뀌지 않게 주의하세요. |
| article | 관사 | 셀 수 있는 명사 하나에는 a/an, 서로 알고 있는 특정한 것에는 the를 써요. 복수나 셀 수 없는 명사를 일반적으로 말할 때는 관사를 쓰지 않아요. |
| preposition | 전치사 | 시간은 at(시각)·on(요일·날짜)·in(월·연도), 장소는 at(지점)·in(안)·on(표면)이 기본이에요. 동사마다 함께 쓰는 전치사가 정해진 경우도 많아요. |
| agreement | 수 일치 | 주어가 3인칭 단수면 현재형 동사에 -s를 붙이고, 복수면 붙이지 않아요. be동사도 주어에 맞춰 is/are, was/were를 골라요. |
| word_choice | 단어 선택 | 뜻은 비슷해도 이 문맥에 어울리지 않는 단어예요. 영어에서 자연스럽게 함께 쓰는 단어 조합을 확인해 보세요. |
| word_order | 어순 | 영어는 주어 + 동사 + 목적어 순서가 기본이에요. 의문문은 조동사(do, be 등)가 주어 앞으로 오고, 간접의문문은 평서문 순서로 돌아가요. |
| other | 기타 | 위 유형에 딱 맞지 않는 오류예요. 고친 문장과 원문을 비교해 보세요. |

- 모르는 type은 `other`로 처리 (TASK 05의 parse 규칙과 같음)
